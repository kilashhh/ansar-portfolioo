# The Shop on Archer — независимый концепт

Готовый англоязычный статический сайт для портфолио. HTML, CSS и обычный JavaScript; сборка, установка пакетов и серверная часть не нужны. Откройте `index.html` в браузере. Для копирования телефона предпочтительнее HTTPS или localhost; при недоступном буфере сайт показывает номер для ручного копирования.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например `archer-concept` (публичные репозитории поддерживаются GitHub Free).
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, `styles.css`, `script.js`, `assets/`, `robots.txt`, `.nojekyll`. Не загружайте ZIP вместо распакованных файлов. `index.html` должен лежать в корне, а не внутри дополнительной папки.
3. Откройте **Settings → Pages → Build and deployment**. Выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, нажмите **Save**.
4. Дождитесь завершения публикации и откройте **Visit site**. Ожидаемый адрес: `https://ВАШ-ЛОГИН.github.io/archer-concept/`. GitHub предупреждает, что публикация может занять до 10 минут.
5. Проверьте меню, ссылки, телефон и карту на своём телефоне. Все локальные пути относительные и работают в подпапке GitHub Pages.

Актуальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Что работает

- Адаптивная компоновка, мобильное меню с Escape и `aria-expanded`.
- Якорная навигация, телефонный `tel:`-переход, Google Maps с адресным поиском.
- Копирование телефона с понятным сообщением об успехе или ручном способе.
- Нативные раскрывающиеся ответы, работающие без JavaScript.
- Без JavaScript навигация остаётся доступной; скрыты только кнопки, которым нужен скрипт.
- Семантические разделы, подписи изображений, фокус клавиатуры, skip-link, поддержка reduced motion.
- Нет форм, аналитики, cookies, внешних шрифтов и запросов к сторонним сервисам при загрузке.

## SEO и честное представление

Добавлены `lang`, viewport, уникальные title/description и Open Graph. **Индексация намеренно отключена** через `noindex,nofollow` и `robots.txt`, чтобы не выдавать портфолио за официальный сайт реального бизнеса. Не добавлены ложный canonical, рейтинги, LocalBusiness-разметка или несуществующий домен.

Для официального запуска после согласования с владельцем: подтвердить все данные; заменить концептные тексты и обозначение статуса; добавить разрешённые фотографии; указать реальный домен в canonical и og:url, абсолютный og:image; настроить sitemap; убрать noindex и запрет robots; при необходимости добавить подтверждённую LocalBusiness-разметку. До этого оставьте обозначение независимого концепта.

## Контент и права

Название относится к реальному бизнесу. Знак с ножницами и иллюстрации созданы для этого проекта и не являются официальными логотипом или фотографиями. Их можно использовать в данном портфолио-концепте. Чужие фотографии и отзывы не скопированы. Имена мастеров, опыт, награды и цены не выдуманы. Подробности проверки — в `RESEARCH.md`.

Фразы про стиль — предложенный рекламный текст, а не цитаты бизнеса. Онлайн-запись не реализована: сайт прямо сообщает об этом. Нажатие телефона может связать посетителя с реальным бизнесом; автоматические тесты звонков не совершали.

## Перед потенциальной продажей

Показывайте проект как самостоятельную инициативу. Уточните у владельца, есть ли собственный сайт: поисковая проверка не доказывает его отсутствие. Согласуйте бренд, контакты, услуги, цены, часы, фотографии и предпочтительную запись. Если нужен Booksy, получите у владельца актуальную прямую ссылку. Не подключайте фиктивную форму бронирования. Для портфолио можно добавить своё имя и реальную ссылку в подвал; они не добавлены, поскольку пользователь их не предоставил.

## Проверка

Проведены проверки в Chrome на ширинах 320, 390, 768 и 1440 px: нет горизонтальной прокрутки, изображения загрузились, страница отвечает HTTP 200. Проверены мобильное меню, закрытие по ссылке и Escape, FAQ, копирование телефона, внутренние якоря, навигация без JavaScript. Ошибок JavaScript в браузере нет. Синтаксис JavaScript проверен отдельно. Десктопный и мобильный скриншоты просмотрены визуально. Это не сертификация WCAG и не проверка в Safari или на физических устройствах; такую проверку следует провести перед продажей.
