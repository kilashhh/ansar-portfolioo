# Ansar — портфолио веб-разработчика

Готовый адаптивный сайт на английском. Главная страница, три отдельных кейса, статическая демонстрация Archer и архивы полных проектов. Сборка и установка библиотек не нужны.

## Открыть

Откройте index.html в браузере или запустите любой статический сервер в этой папке. Все ссылки относительные, поэтому сайт работает и в подпапке GitHub Pages.

## Опубликовать на GitHub Pages

1. Создайте репозиторий GitHub, например `portfolio`.
2. Загрузите **содержимое этой папки** в корень репозитория: index.html должен находиться в корне, рядом с styles.css и папками assets, projects, downloads.
3. Откройте Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите ветку main и папку / (root), нажмите Save.
5. После завершения публикации адрес появится в Pages: `https://ВАШ-ЛОГИН.github.io/portfolio/`.

## Контакты и редактирование

Имя, email, Telegram и WhatsApp находятся в config.js. Тексты страниц — в HTML, оформление — в styles.css. Форма готовит текст заявки для копирования и отправки через email, Telegram или WhatsApp. Серверная отправка и хранение заявок не подключены. Клиент отправляет письмо самостоятельно.

## Что демонстрируют кейсы

- Mori Cuts и Buffalo: полные Node.js приложения с SQLite, регистрацией, записью и защищенной админ-панелью. Архивы доступны на страницах кейсов; инструкции запуска находятся внутри каждого архива. GitHub Pages не запускает их серверную часть.
- Archer: статический сайт, открывается прямо из портфолио.
- Все три проекта независимые и неофициальные. Они не являются заказами этих компаний. Коммерческие результаты, отзывы клиентов и опыт сотрудничества не выдуманы.
- Снимки интерфейсов сделаны с созданных проектов. Фотография интерьера внутри двух проектов — иллюстративный лицензированный stock; атрибуция и исследование находятся в исходных архивах.

Перед коммерческим запуском сайта конкретного бизнеса нужны согласование владельца, актуализация данных и настройка реального хостинга. Для портфолио сайт готов к статической публикации.


## AI advertising

Добавлена услуга AI advertising creative, отдельный кейс ai-advertising.html и варианты заявки. Постер Mori Cuts — независимая AI-кампания; модель вымышленная. PNG и архив с брифом и промптом доступны на странице кейса.
